# ResortOps

Database schema drafts and architecture notes for a hospitality management platform, including resort operations such as bookings, rooms, dining, spa services, activities, and guest accounts.

## Files

- `m.sql`, `d.sql` — Resort and hospitality database schema drafts.
- `k.sql`, `do.sql` — Database schema examples for an architecture and interior-design business.
- `inf.md` — Kuriftu Resorts & Spa product design and architecture brief.
- `k` — Empty placeholder file.

The SQL files are separate drafts/examples and are not intended to be run together. Review each script before running it: some scripts drop or recreate tables/databases and may delete existing data.
